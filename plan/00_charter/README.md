# 00 项目章程

## 目标

在本地完成 YOPO 的数据生成、随机初始化训练、ROS2/Isaac闭环、专家和基线对照，并保留可追溯的模型、日志、指标和可视化成果。

## 范围

- Ubuntu 22.04、ROS2 Humble、Docker训练环境。
- Windows Isaac Sim作为传感器、PhysX和展示环境。
- 本地生成的程序化森林数据。
- 三种正式随机初始化YOPO权重。
- TopoTraj、Agile及参考[17] MPPI的协议化比较。
- DAgger访问数据聚合与独立微调。
