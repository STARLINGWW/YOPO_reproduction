# YOPO 复现交付报告区

报告区面向阅读、复核和展示。它不承载可执行源码；真实产物仍位于根目录的artifacts、checkpoints和datasets。

| 编号 | 入口 | 内容 |
|---|---|---|
| 00 | 00_index | 阅读顺序和报告规则 |
| 01 | 01_status | 当前状态、验收、真实缺口 |
| 02 | 02_method | 论文到本地实现的对应 |
| 03 | 03_training | 正式训练、专家、DAgger |
| 04 | 04_evaluation | 矩阵和权重/基线比较 |
| 05 | 05_visualization | 视频、图片、回放和命令 |
| 06 | 06_migration | GitHub和Ubuntu迁移 |
| 90 | 90_archive | 历史阶段报告 |
| 99 | 99_artifact_index | 产物路径和哈希索引 |

根目录reports保留为运行兼容和历史来源区；当前阅读从本目录开始。
