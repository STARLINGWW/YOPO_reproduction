## 检查与报告同步

```powershell
cd <项目根目录>   # 克隆后的项目根目录
python scripts/queue_status.py --json
python scripts/make_status_overview.py
python scripts/audit_command_evidence.py --fail-on-missing
```

queue_status只读。Docker不可连接时，容器当前状态不可验证，不能把文件complete误读成进程还在运行。make_status_overview会更新报告和status_overview.json，但不训练或改变验收判据。

## 新建从头训练或恢复

实际训练代码为`train_scratch.py`，不是早期Simple的`train_windows.py`。正式数据`datasets/isaac_full_v1`包含100K/10K/10K，已按地图隔离和校验；恢复要求代码、数据、torch版本及训练配置一致。

```powershell
# 仅在确实要做新的训练实验时使用新RunPrefix
./scripts/run_formal_training.ps1 -DatasetName isaac_full_v1 -RunPrefix formal_main_next
```

队列按seed0/1/2串行运行50轮，已有latest.pt时恢复，result和审计通过的种子跳过。每轮验证并选择best_policy，完整检查点用于恢复，只有best_policy不能严格恢复优化器和样本游标。既有formal_main_v1种子最佳轮次为50/47/50。

## 最终权重展示

先确认Docker Linux engine、项目镜像和GPU可用。脚本核查审计及最佳权重哈希，产生新运行名：

```powershell
./scripts/run_final_showcase.ps1 -Seed 0 -Speed 2 -MapSeed 3000 -Duration 60 -Tag final
```

对已有飞行只重渲染，使用新输出标签：

```powershell
./scripts/run_final_showcase.ps1 -Seed 0 -RenderOnly -ExistingRun showcase_formal_main_v1_seed0_20260926_014921 -Tag review_new
```

结果为真实PhysX日志回放，不是实机飞行；展示成功不替代正式矩阵统计。当前正式运行链采用100Hz控制、500Hz物理，名义相机15Hz。

## 官方权重与本地权重对照

```powershell
$isaacPython = $env:YOPO_ISAAC_PYTHON   # 指向本机 Isaac Sim 环境的 python.exe；未设置时脚本会显式报错
& $isaacPython scripts/run_weights_ab_batch.py --scenes 5002,5004,5001 --speeds 2,4,6 --duration 120 --skip-existing
```

脚本默认duration=45，所以本次120秒条件必须显式指定。skip-existing复用旧记录，不能检验修改过的新条件；当前run名固定为wab2组合，tag没有参与命名。扩展重复实验前需增加独立run-id，避免覆盖旧证据。

旧官方Simple展示入口是`run_showcase.ps1`，历史产物和控制判据见[官方阶段验收](../90_archive/01_完成验收与成果路径.md)。不要与最终自训练展示混用。
