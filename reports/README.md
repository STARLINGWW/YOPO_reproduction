## 状态解释与更新方式

- verified表示该验收项有证据；不能把训练verified解释为所有飞行成功。
- documented_gap表示已记录的缺口；pending表示当前判据尚未满足。MPPI和完整1800矩阵的标记正确，不能全部清成完成。
- plan.json的310和运行配置声明的旧pending为历史快照；实际状态以准入、训练审计、DAgger结果与summary为准。
- 方案A/B未应用；固定协议、模型和验收判据保持原样。
- `scripts/make_status_overview.py`更新总览及`status_overview.json`；它现在明确展示历史字段。机器简报为`artifacts/environment/progress_brief.json`。

本次整理备份和文件指纹见[document_refresh_20261008](../artifacts/document_refresh_20261008)。历史原件保存在该目录backups，不删除实验过程证据。
